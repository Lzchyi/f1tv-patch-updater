# F1TV Patch Updater

- `SelfUpdater` owns public-edition self-updates with separate preferences/files/session callbacks. `SelfUpdatePolicy` is host-testable. Check metadata on opening/manual/daily jobs; only Update now downloads and installs. Require the exact own package, matching installed signing certificate, higher code, matching release name and GitHub SHA-256. Never uninstall the updater or switch editions. Recover cleanup through MY_PACKAGE_REPLACED and startup. The persisted automatic_checks setting gates startup/daily checks and automatic offers; explicit manual checks bypass it. Personal builds remain local with no public self-update feed.
- Native Android TV app in `app/src/main/java/com/independent/f1tvupdater`; no third-party runtime dependencies.
- `Updater` owns releases, bounded APKM extraction, split selection, pinned candidate metadata and PackageInstaller sessions. `UpdatePolicy` and `ReleaseCheckPolicy` contain host-testable decisions; `UpdateFiles` owns narrowly scoped staging cleanup. `MainActivity` owns confirmation and Android uninstall requests.
- Never uninstall F1 TV from a background job. Same-key updates preserve data; unrelated keys require the trusted upstream SHA-256, revalidated candidate, explicit data-loss/sign-in warning and Android confirmation. Replacement recovery requires a pinned, user-initiated replacement.
- Check full readable version/build metadata before downloading; uncertain metadata falls back to APK verification. Cache non-newer results by release asset and installed-package identity; invalidate replaced assets. Keep numeric APK version checks authoritative.
- Run resume/startup cleanup off the UI thread under the same operation lock. Delete only updater-owned staging/extraction names, never follow symlinks, preserve valid pending/recovery candidates and active/sealed installer sessions, and make successful-install recovery idempotent.
- Display readable versions; compare numeric version codes. Keep candidates through cancellation/failure. Never permit downgrades. First-time downloads require the activity's explicit Download action and a GitHub SHA-256; pin first-install approval to that verified candidate. Background checks cannot download for an empty TV. Revalidate saved candidates before installation.
- Keep one TV screen, three horizontal actions and the red/white/chevron focus selector. Skip disabled actions; Up reaches the public updater-check pill, Down returns to the main actions, and the personal local-only pill is not focusable. Offer setup automatically once when F1 TV and a saved candidate are absent; Check for updates can offer it again. Show the installed updater version at bottom right in the disclaimer style. Keep the personal-use/subscription and non-affiliation footer visible and credit Alexvbp in public documentation.
- `community` has application ID suffix `.community` and uses the main branding resource. `personal` preserves the original app identity and uses an ignored local overlay at `app/src/personal/res/drawable-nodpi/tv_banner.png`. Do not publish that private overlay or the personal APK.
- JDK 17, Gradle 8.9, Android API 35. CI: `gradle --no-daemon assembleCommunityDebug testCommunityDebugUnitTest lintCommunityDebug`. Personal local check: `assemblePersonalDebug lintPersonalDebug`.
- Public release: `assembleCommunityRelease lintCommunityRelease`, with `UPDATER_KEYSTORE_FILE`, `UPDATER_KEYSTORE_PASSWORD`, `UPDATER_KEY_ALIAS`, `UPDATER_KEY_PASSWORD` supplied privately. Signing material is retained locally, not in Git. Never fall back to a temporary debug key for a public release. CI checks do not publish releases.
- Public APKs and checksums go to GitHub Releases after checks pass. Keep README focused on downloads, usage, screenshots and credits; keep CHANGELOG current. Screenshot only the public edition for public docs, without device/account data.
- Keep `docs/install.md` suitable for non-developers and accurate for the published release. Offer phone/USB routes before ADB; distinguish pairing and legacy network modes. The copyable AI prompt requires local command access, targets only the public updater, and never authorizes app removal or F1 TV changes.
- No simulator tests or launches. Use host tests, static/build checks and an authorized physical-TV ADB connection. Destructive replacement needs explicit consent.
- Never commit APKs, keystores, passwords, local SDK paths or device/app diagnostics. Licence covers updater code, not third-party branding or upstream software.
